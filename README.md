Project: Kanban Board [[demo]([url](https://kanban-seven-ruby.vercel.app/))]
Descriprion: 
Frontend-focused Kanban built with React and localStorage for instant offline persistence. Designed to demonstrate complex client-side state and drag-and-drop without backend latency.
Key features: 
-Built without traditional drag-and-drop project cards over a board containing status column. Instead, uses checkboxes in project card to change color of card related to project status: "not started", "In Progress", "Needs attention", and "Completed".
- Contains editable owner and current action item fields to display current ownership of project and what owner is working on in the project so all partners remain updated on projecrt details.

developer note:
Intentionally avoided traditional dragon drop functionality over status columns due to every resource containing that feature when Kanban was googled.
